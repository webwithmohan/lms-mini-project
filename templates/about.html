About

The Digital Library Management System ( DLMS ) was developed following the comprehensive 10-week educational curriculam designed by Transform Tech to reinforce code clients-side web technologies : HTML5,CSS3,ES6 JAVASCRIPT, and Local Storage

1

Week 1 : Project Setup & Welcome Page

Semantic HTML5 structure ,base CSS styling, vector hero banner, and "Get Started" navigation

2

Week 2 : Login Module & Authentication

Form inputs, non-empty validation, predefined admin credentials, and session persistence

3

Week 3 : Dashboard & Navigation Hub

Interactive sidebar navigation, real-time summary cards, and quick action shortcuts.

4

Week 4 :Book Management --- Part 1( View & Add )

Semantic HTML5 structure ,base CSS styling, vector hero banner, and "Get Started" navigation

5

Week 5 : Book Management -- Part 2 ( Edit, Delete & Add )

Full CRUD operation with edit modal prefilling, deletion dialogs, and instant live filtering.

6

Week 6 : Member Management -- Part 1 ( View & Edit )

Student / Faculty member directory, regex validation for email and 10-digit phone numbers.

7

Week 7 : Member Management -- Part 2 ( Edit, Delete & Search )

Consolidated CRUD patters, modal edits, delete confirmation, and multi-field live search.

8

Week 8 : Issue Book Module.

Relation Data flow connecting books & members , stocks verification, and automatic inventory decrement.

9

Week 9 : Return Book Module & Dynamic Reports.

Borrowing cycle closure, inventory replenishment, dynamic counties, and category distribution.

10

Week 10 : Logout, Integration & Presentation

Session changing, end-to-end flow verification, responsive layout polishing, and clean codebase.
